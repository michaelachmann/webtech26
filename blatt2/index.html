CSS an HTML binden

Inline, intern, extern — und warum nur eine Variante in die Produktion gehört.

MDN CSS in HTML einbinden CSS-Übersicht
  1. Inline CSS: Färbt eure <h1> testweise direkt im Tag rot: 
    <h1 style="color: red;">Mein erstes Web-Dokument</h1>
  2. Internal CSS: Entfernt das style-Attribut wieder und fügt im <head> einen <style>-Block ein: 
    <style>
  h1 { color: red; }
</style>
  3. External CSS: Legt im Projektordner einen Unterordner css/ an, darin die Datei style.css. Verschiebt die Regel h1 { color: red; } dort hinein und ersetzt den <style>-Block im <head> durch: 
    <link rel="stylesheet" href="css/style.css">
  4. Probe: Ändert in style.css die Farbe auf blue und ladet die HTML-Seite neu. Der Browser hat die CSS-Datei automatisch nachgeladen — ihr habt die Darstellung verändert, ohne das HTML anzufassen.
Separation of Concerns HTML beschreibt Struktur & Inhalt, CSS beschreibt Form & Layout. Externes CSS ist deshalb die einzige Variante, die ihr produktiv verwenden solltet — nur so lassen sich Inhalt und Gestaltung unabhängig pflegen (vgl. CSS Zen Garden: ein HTML-Dokument, viele Designs).

Aufbau einer CSS-Regel & Typografie

Selektor, Eigenschaft, Wert — und erste Gestaltung.

MDN CSS-Syntax Schrift-Eigenschaften Text-Eigenschaften

Eine CSS-Regel besteht aus Selektor und einem Block mit Eigenschaft–Wert-Paaren:

selektor {
  eigenschaft: wert;
  weitere-eigenschaft: wert;
}
  1. Setzt im body eine angenehme Lese-Schriftart und Grundfarbe. Tipp: font-family akzeptiert eine Liste — der Browser nimmt die erste Schrift, die er findet. 
    body {
  font-family: Georgia, "Times New Roman", serif;
  color: #222;
  line-height: 1.6;
}
  2. Vergrößert eure <h1> und zentriert sie. Schaut auf MDN nach den Eigenschaften font-size und text-align.
  3. Probiert font-weight, font-style und text-decoration auf einem Absatz aus. Welche Werte nimmt jede Eigenschaft an? (Antwort in der MDN-Doku der jeweiligen Eigenschaft.)
  4. Mehrere Selektoren auf einmal: Eine Regel kann für mehrere Selektoren gelten, getrennt durch Komma. Gebt allen Überschriften zugleich eine andere Schriftart: 
    h1, h2, h3 {
  font-family: "Helvetica Neue", Arial, sans-serif;
}
Mini-Reflexion Schaut euch eure Seite an — und dann eine Lieblings-Website mit den DevTools (Rechtsklick → Untersuchen → Tab Styles). Findet ihr in der echten Website Regeln wieder, die ihr jetzt selbst geschrieben habt?

Selektoren: Typ, ID, Klasse

Wie wähle ich gezielt einzelne, mehrere oder gruppierte Elemente aus?

MDN Selektoren — Übersicht class-Attribut id-Attribut

Drei Selektoren reichen für 90 % aller Fälle:

p          { /* Typ-Selektor: alle <p>-Elemente */ }
.zitat     { /* Klassen-Selektor: alle Elemente mit class="zitat" */ }
#intro     { /* ID-Selektor: das eine Element mit id="intro" */ }
  1. Typ-Selektor: Gebt allen <li>-Elementen einen kleinen linken Innenabstand (padding-left) und eine andere Textfarbe.
  2. Klassen-Selektor: Vergebt im HTML an einen eurer Absätze die Klasse class="highlight" und stylt diese Klasse in CSS: 
    <p class="highlight">Dieser Absatz ist besonders wichtig.</p>
    .highlight {
  background-color: #FFF3B0;
  padding: 8px 12px;
  font-style: italic;
}

    Dieser Absatz ist besonders wichtig.

  3. ID-Selektor: Gebt eurer <h2> „Über mich“ aus Blatt 01 die id="about" (falls noch nicht geschehen) und stylt ausschließlich dieses Element über #about { ... }.
  4. Mehrere Klassen kombinieren: Ein Element darf mehrere Klassen tragen — getrennt durch ein Leerzeichen. Probiert: 
    <p class="highlight small">Wichtig, aber leise.</p>
    Schreibt eine zweite Klasse .small { font-size: 0.85em; } und beobachtet, dass beide Regeln gleichzeitig wirken.
Faustregel id nur einmal pro Seite verwenden (z. B. für einen Anker oder Anker-Sprung). class dagegen beliebig oft — das ist das Werkzeug, mit dem man wiederverwendbare Stile baut. Frameworks wie Bootstrap arbeiten ausschließlich mit Klassen.

Farben & Einheiten

Vier Wege, eine Farbe zu schreiben — und der Unterschied zwischen px, em und %.

MDN Farben Werte & Einheiten

Eine Farbe lässt sich auf vier verschiedene Arten ausdrücken — alle vier Zeilen ergeben dasselbe Rot:

color: red;                  /* Farbname  */
color: #FF0000;              /* Hex       */
color: rgb(255, 0, 0);       /* RGB       */
color: rgba(255, 0, 0, 0.5); /* RGB + Alpha (50 % transparent) */

Absatz mit rgba(184, 80, 66, 0.15)-Hintergrund — die Schrift bleibt lesbar, weil nur 15 % Deckkraft.

  1. Gebt eurer Seite eine dezente Hintergrundfarbe für den body (z. B. #FAF7F2) und eine andere für einen <section>-Block. Sucht euch die Hex-Codes mit dem Browser-Color-Picker oder unter MDN – named-color.
  2. Transparenz: Setzt auf einem Absatz background-color: rgba(184, 80, 66, 0.15); und vergleicht mit rgb(...) ohne Alpha. Der Wert hinter dem Komma steuert die Deckkraft (0 = unsichtbar, 1 = voll).
  3. Längen vergleichen: Setzt drei aufeinanderfolgende Absätze auf jeweils font-size: 16px, font-size: 1em und font-size: 120%. Was passiert, wenn ihr nun body { font-size: 20px; } hinzufügt?
  4. Mini-Reflexion: px ist eine absolute Einheit, em und % sind relativ. Warum ist Letzteres für Barrierefreiheit (Schrift im Browser vergrößerbar!) wichtig?

Block vs. Inline & die display-Eigenschaft

Vier farbige Kästen — und warum sie untereinander stehen.

MDN display div span

Legt eine neue Datei boxen.html an mit folgendem Inhalt:

<!DOCTYPE html>
<html lang="de">
<head>
  <meta charset="utf-8">
  <title>Boxen</title>
  <link rel="stylesheet" href="css/boxen.css">
</head>
<body>
  <div id="container">
    <div id="green"  class="box"></div>
    <div id="blue"   class="box"></div>
    <div id="yellow" class="box"></div>
    <div id="red"    class="box"></div>
  </div>
</body>
</html>

… und eine Datei css/boxen.css:

#container {
  width: 500px;
  padding: 5px;
  margin: 50px auto;
  background-color: #FAFAFA;
}
.box {
  width: 100px;
  height: 100px;
  margin: 20px;
  border: solid 1px #000;
}
#green  { background-color: green;  }
#blue   { background-color: blue;   }
#yellow { background-color: yellow; }
#red    { background-color: red;    }
  1. Öffnet boxen.html im Browser. Warum stehen die vier Boxen untereinander, obwohl im Container reichlich Platz wäre? (Stichwort: <div> ist ein Block-Element.)
  2. Ergänzt in .box die Zeile display: inline-block;. Was ändert sich? Lest auf MDN nach, was inline-block von block unterscheidet.
  3. display: none: Blendet die gelbe Box mit #yellow { display: none; } aus. Was passiert mit dem Platz, den sie vorher belegt hat? Vergleicht mit visibility: hidden; — wo liegt der Unterschied?
  4. span vs. div: Fügt in einem Absatz auf eurer HelloWorld-Seite ein <span class="marker">…</span> um ein einzelnes Wort ein und gebt ihm einen gelben Hintergrund. Versucht dasselbe mit <div class="marker"> — was passiert?

Positionierung: static, relative, absolute, fixed

Vier Modi — und wann ihr welchen braucht.

MDN position z-index

Erweitert boxen.css aus der vorherigen Aufgabe. Ergänzt zuerst den Container — das wird gleich wichtig:

#container {
  position: relative;   /* macht den Container zum Bezugsrahmen */
  /* … andere Eigenschaften bleiben */
}
  1. relative: Schiebt die blaue Box relativ zu ihrer ursprünglichen Position nach rechts: 
    #blue {
  background-color: blue;
  position: relative;
  top: 0px;
  left: 50px;
}
    Beobachtet: Der Platz, an dem die Box „eigentlich“ wäre, bleibt freigehalten.
  2. absolute: Ändert bei #blue die Eigenschaft auf position: absolute;. Was passiert? Die Box wird aus dem normalen Fluss gerissen — andere Elemente rücken nach. Sie positioniert sich nun relativ zum nächsten positionierten Vorfahren (deshalb haben wir oben #container { position: relative; } gesetzt).
  3. fixed: Setzt stattdessen position: fixed; top: 10px; right: 10px; auf #blue. Scrollt die Seite (ggf. Inhalte verlängern). Wo bleibt die Box? — Genau so funktionieren Cookie-Banner und Sticky-Header.
  4. z-index: Setzt #blue wieder auf position: absolute; top: 0; left: 0; — die Box überlappt nun die grüne. Setzt zusätzlich z-index: 10; auf #green. Schaut, wer jetzt oben liegt, und lest auf MDN nach, wie z-index die Stapelreihenfolge bestimmt.
Merksatz static = normal im Fluss · relative = im Fluss, aber verschoben · absolute = aus dem Fluss, relativ zum positionierten Vorfahren · fixed = aus dem Fluss, relativ zum Viewport (scrollt nicht mit).

Mehrspaltige Layouts: float & Spalten

Wie aus mehreren Boxen ein Magazin-Layout wird — der Ursprung von Bootstrap & Co.

MDN float clear

Legt eine neue Datei spalten.html mit drei Spalten an und bindet eine neue css/spalten.css ein:

<section class="row">
  <div class="column"><h3>Spalte 1</h3><p>Lorem ipsum dolor sit amet …</p></div>
  <div class="column"><h3>Spalte 2</h3><p>Lorem ipsum dolor sit amet …</p></div>
  <div class="column"><h3>Spalte 3</h3><p>Lorem ipsum dolor sit amet …</p></div>
</section>
  1. Floating: Lasst alle drei Spalten nebeneinander schwimmen: 
    .column {
  float: left;
  width: 29%;
  margin: 1%;
  padding: 1%;
  background-color: #1E2761;
  color: white;
  text-align: justify;
  line-height: 1.5;
}

    Spalte 1

    Lorem ipsum dolor sit amet, consectetur adipisicing elit, sed do eiusmod tempor incididunt.

    Spalte 2

    Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi ut aliquip ex ea commodo.

    Spalte 3

    Duis aute irure dolor in reprehenderit in voluptate velit esse cillum dolore eu fugiat nulla pariatur.

    Rechnet kurz nach: drei Spalten à 29% + 2 × 1% margin + 2 × 1% padding ≈ 33%. So bleibt das Layout flexibel.
  2. Variation: Ändert die Spaltenanzahl auf zwei und passt nur die width der .column an (auf ca. 46%). Das HTML kann identisch bleiben — nur das CSS ändert sich.
  3. Ausblick: Schaut euch die Bootstrap-Grid-Doku an. Findet die Klassennamen row, col, col-6, col-4 — und erkennt, dass Bootstrap im Kern genau das macht, was ihr gerade selbst geschrieben habt. Welcher Vorteil entsteht durch vorgefertigte Klassen?
Mini-Reflexion Heute baut man Spalten meist mit display: flex oder display: grid — moderner und robuster, mit weniger Tücken. float versteht ihr aber, weil es jahrzehntelang das Standardwerkzeug war und in vielen Bestands-Sites noch lebt. Gleich seht ihr außerdem, wie Bootstrap genau diese Aufgabe in fertige Klassen verpackt.

Bootstrap: Fertige Klassen statt eigenem CSS

Eure Spalten aus Aufgabe H — diesmal in 5 Minuten, ohne eine Zeile CSS.

Bootstrap Getting Started Grid Alerts Utilities
  1. Bootstrap einbinden: Legt eine neue Datei bootstrap.html mit dem HTML5-Grundgerüst an. Fügt im <head> vor eurem eigenen Stylesheet diese Zeile ein: 
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    Das ist ein CDN-Link: der Browser lädt das Stylesheet von einem öffentlichen Server. Eure Seite hat damit sofort Zugriff auf alle Bootstrap-Klassen.
  2. Grid statt Float: Baut die drei Spalten aus Aufgabe H neu — ohne eigene CSS-Datei. Bootstrap bringt drei Klassen mit: container (zentriert), row (Spalten-Zeile) und col-md-4 (eine Spalte, die auf mittleren Bildschirmen 4 von 12 Rastereinheiten breit ist). 
    <div class="container">
  <div class="row">
    <div class="col-md-4">
      <div class="card p-3">Spalte 1</div>
    </div>
    <div class="col-md-4">
      <div class="card p-3">Spalte 2</div>
    </div>
    <div class="col-md-4">
      <div class="card p-3">Spalte 3</div>
    </div>
  </div>
</div>
    Verkleinert das Browserfenster. Was passiert mit den Spalten unter ca. 768 px Breite? Das ist responsive design — bei Bootstrap frei Haus.
  3. Fertige Komponente: Fügt oberhalb des Grids einen blauen Hinweiskasten ein: 
    <div class="alert alert-primary" role="alert">
  Hinweis: Bootstrap bringt fertige Bauteile mit.
</div>
    Probiert auch alert-success, alert-warning, alert-danger. Das sind keine Farben, die ihr selbst wählt — das sind semantische Klassen.
  4. Utility-Klassen: Stylt eine Überschrift komplett über Klassen — ganz ohne eigene CSS-Datei: 
    <h1 class="text-center text-primary mt-5 mb-3">Hallo Bootstrap!</h1>
<button class="btn btn-primary">Klick mich</button>
    Entschlüsselt die Klassen mit der Spacing-Doku: mt-5 = margin-top, Stufe 5; mb-3 = margin-bottom, Stufe 3; p-3 = padding rundum, Stufe 3. Das Schema gilt für alle Bootstrap-Klassen.
  5. Reflexion: Vergleicht bootstrap.html mit eurer Lösung aus Aufgabe H. Wieviel CSS habt ihr eingespart? Und: Warum lohnt es sich trotzdem, die CSS-Grundlagen aus diesem Blatt verstanden zu haben — auch wenn man später nur noch Frameworks nutzt?
