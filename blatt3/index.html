A Die Konsole als Taschenrechner

Aufwärmen · ein paar Minuten

MDN console.log()

Bevor wir programmieren, machen wir uns mit der Konsole vertraut. Sie rechnet sofort, was du eingibst. Tippe Zeile für Zeile, jeweils gefolgt von Enter:

Konsole 8 + 5 13 10 / 4 2.5 console.log("Hallo Welt") Hallo Welt

Punkt-vor-Strich gilt auch hier. Klammern setzen, wo nötig: (8 + 5) * 2.

Probier es aus
  1. Rechne in der Konsole aus, wie viele Stunden 135 Minuten sind.
  2. Gib mit console.log(...) deinen Namen aus. Text muss in "Anführungszeichen" stehen.
  3. Was passiert bei "7" + 3? Und bei 7 + 3? Notiere den Unterschied – darauf kommen wir in C zurück.

B Variablen: let und const

Grundlage · 5–10 Min

MDN let const

Eine Variable ist ein benannter Behälter für einen Wert. Mit let legst du einen Behälter an, dessen Inhalt sich noch ändern darf; mit const einen, der fest bleibt.

Konsole // anlegen mit Startwert let alter = 21 alter 21 // neu zuweisen (geht nur bei let) alter = alter + 1 22 // const lässt sich nicht überschreiben const kursname = "Webtechnologien" kursname = "Mathe" Uncaught TypeError: Assignment to constant variable.

Das = ist keine Gleichung, sondern eine Zuweisung: „nimm den Wert rechts und lege ihn in den Behälter links". Variablennamen schreibt man klein und ohne Leerzeichen, oft in camelCase (z. B. maxPunkte).

🐍 Python-Vergleich In Python schreibst du einfach alter = 21 ohne Schlüsselwort. In JavaScript deklarierst du eine Variable einmal mit let bzw. const; danach reicht der Name. Faustregel: nimm const, und nur let, wenn sich der Wert ändern soll.
Probier es aus
  1. Lege let punkte = 0 an, erhöhe sie zweimal um 10 und gib den Endstand aus.
  2. Lege eine const für deinen Geburtsort an und versuche, sie zu überschreiben. Lies die Fehlermeldung.

C Datentypen: Text, Zahl, Wahrheitswert

Grundlage · 5–10 Min

MDN typeof Datentypen

Werte haben einen Typ. Drei brauchst du heute ständig:

  • String – Text in "…" oder '…'
  • Number – Zahlen, mit Punkt als Dezimaltrennzeichen: 3.5
  • Boolean – die Wahrheitswerte true oder false

Mit typeof fragst du den Typ eines Wertes ab:

Konsole typeof "Mara" 'string' typeof 42 'number' typeof true 'boolean'
Achtung Falle: "7" (mit Anführungszeichen) ist ein String, 7 ist eine Zahl. Deshalb war "7" + 3 in Aufgabe A das Ergebnis "73" – JavaScript hat die Zahl an den Text angeklebt statt zu rechnen.
🐍 Python-Vergleich typeof entspricht type(). true/false werden in JS klein geschrieben (in Python groß: True/False).
Probier es aus
  1. Lass dir den Typ von "true" (mit Anführungszeichen) und von true (ohne) anzeigen. Erkläre dir den Unterschied.
  2. Was ist typeof (5 > 2)? Überlege erst, dann ausprobieren.

D Strings & Template Literals

Grundlage · 10 Min

MDN Template-Strings String

Texte lassen sich zusammensetzen. Klassisch mit + – oder, viel bequemer, mit Template Literals: Text in Backticks `…`, in den du mit ${…} Werte einsetzt.

Konsole let name = "Mara" // zusammenkleben mit + "Hallo " + name + "!" 'Hallo Mara!' // dasselbe als Template Literal (Backticks!) `Hallo ${name}!` 'Hallo Mara!' // in ${…} darf auch gerechnet werden `In 5 Jahren bist du ${21 + 5}.` 'In 5 Jahren bist du 26.'

Den Backtick ` findest du auf deutscher Tastatur über Shift + ´ (Taste links neben Backspace) – er erscheint oft erst nach dem nächsten Tastendruck.

Strings können auch etwas über sich selbst sagen: name.length gibt die Anzahl der Zeichen, name.toUpperCase() eine Großbuchstaben-Version.

🐍 Python-Vergleich Template Literals sind die f"…"-Strings von JavaScript: `Hallo ${name}` ↔ f"Hallo {name}" – nur mit Backticks und Dollarzeichen. Diese Schreibweise brauchen wir in Aufgabe J für die Ausgabe.
Probier es aus
  1. Bau dir einen Begrüßungssatz mit deinem Namen als Template Literal.
  2. Lass dir die Länge deines Namens mit .length ausgeben.
  3. Gib `${i}: ${text}` aus, nachdem du i = 0 und text = "Einkaufen" gesetzt hast. Diese Zeile begegnet dir in Aufgabe J wieder.

E Arrays: Listen von Werten

Kernbaustein · 10–15 Min

MDN Array push() includes()

Ein Array ist eine geordnete Liste. Du schreibst sie in eckige Klammern [ ]. Jeder Eintrag hat eine Position, den Index – und der beginnt bei 0.

Konsole let einkauf = ["Brot", "Milch", "Apfel"] // auf einen Eintrag zugreifen (Index in [ ]) einkauf[0] 'Brot' einkauf[2] 'Apfel' // wie viele Einträge? einkauf.length 3 // hinten etwas anhängen einkauf.push("Käse") einkauf ['Brot', 'Milch', 'Apfel', 'Käse']

Weil der Index bei 0 startet, ist der letzte Eintrag immer an Position length - 1. .push() hängt einen neuen Eintrag ans Ende – genau das brauchen wir gleich für neue Todos.

Ein paar weitere Array-Funktionen, die oft nützlich sind:

Konsole // letzten Eintrag entfernen (und zurückgeben) einkauf.pop() 'Käse' // ist etwas enthalten? einkauf.includes("Milch") true // an welcher Position steht es? (-1 = nicht gefunden) einkauf.indexOf("Apfel") 2
🐍 Python-Vergleich Arrays sind die list von JavaScript. .push() heißt in Python .append(); .length heißt len(...). Der Index startet wie gewohnt bei 0. (Negativ-Indizes wie liste[-1] gibt es in JS aber nicht.)
Probier es aus
  1. Lege ein Array farben mit drei Farben an.
  2. Gib die zweite Farbe aus. Welcher Index ist das?
  3. Häng mit .push() eine vierte Farbe an und lass dir die neue .length ausgeben.
  4. Prüfe mit .includes(...), ob eine bestimmte Farbe enthalten ist, und entferne mit .pop() die letzte.

F Objekte: Werte mit Namen

Kernbaustein · 10–15 Min

MDN Object Object.keys() Mit Objekten arbeiten

Ein Objekt bündelt zusammengehörige Werte unter Namen (statt unter Nummern wie beim Array). Du schreibst es in geschweifte Klammern { } als Paare aus name: wert.

Konsole let todo = { text: "Einkaufen", erledigt: false } // Eigenschaft mit dem Punkt auslesen todo.text 'Einkaufen' todo.erledigt false // Eigenschaft ändern todo.erledigt = true todo { text: 'Einkaufen', erledigt: true }

Die Namen text und erledigt haben wir frei gewählt – sie beschreiben, was drinsteht. Genau dieses Objekt ist die Form, die ein einzelnes Todo später hat.

Du kannst jederzeit neue Eigenschaften hinzufügen und dir alle Namen geben lassen:

Konsole // neue Eigenschaft anlegen todo.prioritaet = "hoch" todo { text: 'Einkaufen', erledigt: true, prioritaet: 'hoch' } // alle Eigenschaftsnamen als Array Object.keys(todo) ['text', 'erledigt', 'prioritaet'] // gibt es diese Eigenschaft? "text" in todo true
🐍 Python-Vergleich Objekte ähneln dem dict – aber du liest Eigenschaften mit dem Punkt aus (todo.text) statt mit eckigen Klammern (todo["text"]). Beachte: false/true klein, kein None, sondern null.
Probier es aus
  1. Erstelle ein Objekt person mit den Eigenschaften name (String) und alter (Number).
  2. Gib person.name aus und erhöhe person.alter um 1.
  3. Baue ein Array liste = [todo, person] – ein Array darf Objekte enthalten. Greif mit liste[0].text zu.
  4. Füge person eine neue Eigenschaft stadt hinzu und lass dir mit Object.keys(person) alle Namen ausgeben.

G Vergleiche, if/else und das !

Kernbaustein · 15 Min

MDN Vergleichsoperatoren if...else

Mit Vergleichen entstehen Wahrheitswerte. Wichtig: zum Vergleichen nimmt man in JavaScript drei Gleichheitszeichen === (ein einzelnes = ist die Zuweisung!).

Konsole 5 > 2 true 3 === 3 true 3 === 4 false // ungleich: != "a" != "b" true

Mit if/else lässt du Code nur dann laufen, wenn eine Bedingung true ist. In der Konsole tippst du den Block mit Shift+Enter mehrzeilig – oder du schreibst ihn gleich in script.js:

js/script.js let stunde = 20; if (stunde < 18) { console.log("Guten Tag"); } else { console.log("Guten Abend"); }
Konsole · Ausgabe Guten Abend

Ein Spezialwerkzeug für Booleans ist das Ausrufezeichen !: es dreht einen Wahrheitswert um.

Konsole let erledigt = false erledigt = !erledigt true erledigt = !erledigt false

Dieses Umschalten (!erledigt) ist der Trick hinter dem Abhaken eines Todos.

🐍 Python-Vergleich === ist das == aus Python (JS hat zusätzlich ein lockereres == – das meiden wir, nimm immer ===). Das ! ist Pythons not; && und || sind and und or. Blöcke werden mit { } geklammert statt durch Einrückung.
Probier es aus
  1. Schreib ein if/else, das je nach Variable punkte entweder "bestanden" (ab 50) oder "nicht bestanden" ausgibt.
  2. Setze let licht = true und schalte es zweimal mit licht = !licht um. Beobachte die Werte.

H Schleifen: jeden Eintrag durchgehen

Kernbaustein · 15 Min

MDN for

Eine Schleife wiederholt Code. Um ein Array Eintrag für Eintrag durchzugehen, nutzen wir eine for-Schleife mit einem Zähler i, der von 0 bis länge - 1 läuft. Schreib das in script.js und lade neu:

js/script.js let einkauf = ["Brot", "Milch", "Apfel"]; for (let i = 0; i < einkauf.length; i++) { console.log(`${i}: ${einkauf[i]}`); }
Konsole · Ausgabe 0: Brot 1: Milch 2: Apfel

Die drei Teile in den Klammern bedeuten: Start (let i = 0), Bedingung zum Weitermachen (i < länge) und Schritt (i++, also „erhöhe i um 1"). So besucht einkauf[i] jeden Eintrag.

🐍 Python-Vergleich Diese Schleife entspricht for i in range(len(einkauf)):. Es gibt in JS auch eine kürzere Form ohne Zähler – for (let x of einkauf) ↔ for x in einkauf: – aber den Index i brauchen wir gleich für die Ausgabe, deshalb die Zähler-Variante.
Probier es aus
  1. Lass deine farben aus Aufgabe E mit einer for-Schleife samt Index ausgeben (0: …, 1: … …).
  2. Zähle in einer Schleife von 1 bis 5 und gib jede Zahl aus. (Tipp: i = 1 starten, i <= 5.)

I Funktionen: Code mit Namen

Kernbaustein · 15–20 Min

MDN Funktionen return

Eine Funktion ist ein benannter, wiederverwendbarer Code-Block. Du definierst sie einmal und rufst sie dann beliebig oft auf. In den Klammern stehen Parameter – Werte, die du von außen hineingibst.

js/script.js // definieren function begruesse(name) { console.log(`Hallo ${name}!`); } // aufrufen – mit verschiedenen Werten begruesse("Mara"); begruesse("Jonas");
Konsole · Ausgabe Hallo Mara! Hallo Jonas!

Manche Funktionen geben einen Wert zurück – mit return. Der Aufruf „wird dann zu" diesem Wert. Sind die Funktionen in script.js definiert, kannst du sie auch direkt in der Konsole aufrufen:

js/script.js function quadrat(zahl) { return zahl * zahl; }
Konsole quadrat(5) 25

Nach einem return ist die Funktion sofort zu Ende – das nutzen wir gleich, um den Sonderfall „leere Liste" früh abzufangen.

🐍 Python-Vergleich function name(...) { … } ist Pythons def name(...):. return funktioniert identisch. Statt Einrückung klammert { } den Funktionskörper.
Probier es aus
  1. Schreib eine Funktion verdopple(zahl), die mit return das Doppelte zurückgibt. Teste sie mit drei Werten.
  2. Schreib eine Funktion begruesseAlle(namen), die ein Array bekommt und in einer Schleife jeden Namen begrüßt. (Du kombinierst hier H und I.)

J Projekt: Die Todo-Logik

Das Ziel des Blattes · 20–30 Min

MDN push() Object

Jetzt fügt sich alles zusammen. In script.js bauen wir das „Gehirn" einer Todo-Liste: eine Liste von Todo-Objekten und drei Funktionen, die sie verwalten. Noch ganz ohne Webseite – die Ausgabe bleibt in der Konsole. (In JavaScript II bekommt dieses Gehirn dann ein Gesicht.)

Du brauchst dafür nichts Neues – nur die Bausteine A–I: ein Array (E), Objekte mit text und erledigt (F), .push() (E), das ! zum Umschalten (G), eine Schleife (H), if (G) und ein Template Literal für die Zeile (D).

1. Die Daten. Lege ganz oben in script.js eine leere Liste an:

js/script.js let todos = [];

2. addTodo(text) – baut aus dem Text ein Objekt (neue Todos sind erledigt: false) und hängt es an:

js/script.js function addTodo(text) { let neuesTodo = { text: text, erledigt: false }; todos.push(neuesTodo); }

3. toggleTodo(index) – holt das Todo an der Position index und dreht seinen erledigt-Wert um. Versuch diese zuerst selbst, bevor du spickst:

Tipp: Hol dir das Todo mit let todo = todos[index] und setze todo.erledigt = !todo.erledigt. Das ! aus Aufgabe G macht aus false ein true und umgekehrt.

4. renderTodos() – gibt die ganze Liste aus. Fang den leeren Fall mit if und return ab, geh sonst mit einer Schleife durch und baue pro Eintrag eine Zeile wie 0: [ ] Einkaufen bzw. 1: [x] Pause:

Tipp zur Zeile: Wähle das Kästchen mit if (todo.erledigt) { box = "[x]" } else { box = "[ ]" } und gib dann `${i}: ${box} ${todo.text}` aus.

5. Ausprobieren. Ruf deine Funktionen am Ende von script.js auf, speichere und lade neu:

js/script.js addTodo("Einkaufen gehen"); addTodo("Übungsblatt anschauen"); renderTodos(); toggleTodo(0); renderTodos();
Konsole · Ausgabe --- Deine Todos --- 0: [ ] Einkaufen gehen 1: [ ] Übungsblatt anschauen --- Deine Todos --- 0: [x] Einkaufen gehen 1: [ ] Übungsblatt anschauen
Probier es aus
  1. Schreib die drei Funktionen in js/script.js – so sind sie beim Neuladen wieder da.
  2. Lege drei Todos an, hake eines ab und lass dir die Liste zweimal ausgeben (vorher / nachher).
  3. Stecken geblieben? Die Musterlösung liegt in js/script.solution.js mit ausführlichen Kommentaren – aber erst selbst probieren. Um sie laufen zu sehen, kannst du unten in der HTML-Datei kurz script.js gegen script.solution.js tauschen und neu laden.
